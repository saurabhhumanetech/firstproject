# ariessgurlll._ ♡ | A Little Corner of the Internet

> A cute, personalized, mobile-first romantic website dedicated to **ariessgurlll._**, created with love by **Saurabh** ♡.

---

## 🌸 Features

- **Personalized Story & Aesthetic**: Baby pink, soft blush romance, and playful scrapbook aesthetic with washi tape, cute polaroids, and subtle sparkle/heart motifs.
- **Interactive Heart Reveal**: Tap to discover who is in Saurabh's heart, revealing a sweet framed portrait and playful teasing text.
- **Two-Song Section**: Songs from her story (*mirrorball*) and dedicated by Saurabh (*Lover*) with Spotify links and in-browser gentle music-box chime melody previews.
- **Scrapbook Photo Gallery**: 3 polaroids with custom captions and tap-to-zoom Lightbox modal.
- **One Little Moment**: Styled phone container with the authentic Marathi confession screenshot (*“मला तू खूप आवडते 🤭”*).
- **The Question / Proposal**: Interactive *“will you be my girlfriend? ♡”* with celebration confetti, chimes, and a warm, non-pressuring response flow.
- **Digital Handwritten Love Note**: Warm reminders to stay hydrated, sleep well, and be happy, ending with an animated beating heart.
- **Centralized Configuration**: Easily edit handles, song details, and links in [`src/config.ts`](src/config.ts).

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Vanilla CSS Design Tokens (Baby Pink Scrapbook Theme)
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti
- **Audio**: Web Audio API (Synthesized romantic chimes & melodies)
